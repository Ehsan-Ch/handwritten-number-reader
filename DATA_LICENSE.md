# UCI digit data attribution

E. Alpaydin and C. Kaynak (1998). *Optical Recognition of Handwritten Digits*. UCI Machine Learning Repository. DOI: [10.24432/C50P49](https://doi.org/10.24432/C50P49).

Source: https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits

The project's MIT code license does not replace the dataset license. The report embeds the 1,797 official test arrays, renders them as enlarged grayscale grids and combines selected arrays into synthetic four-digit examples. These adaptations are created by this project, not by the dataset authors. Attribution must be retained when redistributing the data-containing report. No endorsement is implied.

Archive and file fingerprints are recorded in reports/benchmark/metrics.json. The original data description is downloaded alongside the raw files when running the download command.
